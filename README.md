# CSES Problem Set Solutions

A collection of my solutions to the **CSES Problem Set**, written while practicing competitive programming and strengthening problem-solving skills.

The goal of this repository is to provide clean, understandable, and efficient solutions with a focus on common algorithms and data structures.

## 📚 About CSES

The [CSES Problem Set](https://cses.fi/problemset/) is a collection of competitive programming problems covering topics such as:

* Introductory Problems
* Range Queries
* Sorting and Searching


> The folder structure may change as more problems are solved.

## 💻 Solutions

Each solution is organized according to its corresponding CSES problem category.

Solutions aim to be:

* ✅ Correct and efficient
* 📖 Easy to understand
* 🚀 Suitable for competitive programming
* 🧠 Focused on the underlying algorithm and problem-solving approach
